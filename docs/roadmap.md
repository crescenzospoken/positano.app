# Roadmap

## Fase 0 — Fondazioni ✅
Repository pubblico, licenza EUPL-1.2, publiccode.yml, scheletro PWA bilingue offline-first, struttura dati JSON.

## Fase 1 — MVP (in corso)
- Verifica sul campo di tutti i dati segnati "da verificare"
- Calendario rifiuti per zona + notifica promemoria
- Orari bus e collegamenti marittimi strutturati (accordi con i gestori)
- Icone PNG definitive e identità visiva
- Migrazione UI a Bootstrap Italia (design system PA, accessibilità WCAG 2.1 AA)
- Censimento parcheggi con tariffe; tariffe taxi ufficiali
- Beta chiusa con 30–50 utenti locali; lancio pubblico

## Fase 2 — Partecipazione e trasparenza
- Segnalazioni civiche: foto + posizione + categoria, senza account, con stato pubblico della pratica (backend leggero: Cloudflare Workers + D1)
- "Radar albo pretorio": monitoraggio automatico di ordinanze e delibere con notifiche push (GitHub Actions + Web Push)
- Avvisi push (allerte meteo, interruzioni servizi, viabilità)
- Terze lingue via traduzione assistita (DE/FR/ES)

## Fase 3 — Adozione istituzionale
- Valutazione comparativa ex art. 68 CAD e delibera di adozione da parte del Comune
- Pubblicazione nel catalogo del riuso di Developers Italia
- Integrazione con i servizi nazionali (App IO / PagoPA per pagamenti e comunicazioni formali)
- Store nativi (wrapper PWA) con account istituzionali

## Fase 4 — Innovazione
- Assistente multilingue basato su AI, limitato ai contenuti locali verificati
- Mappa "Positano accessibile" (percorsi con meno scale, accessi facilitati)
- Gestione flussi turistici (dati anonimi di affollamento, percorsi alternativi)
- Open data del Comune integrati nell'app
- Pacchettizzazione per il riuso da parte di altri comuni ("fork kit")
